# Tinkr

**Make the physical world programmable.**

Tinkr is a reusable engine that turns natural-language instructions into structured rules
and checks them in real time against coloured objects seen through a webcam. An LLM
*compiles* the instruction, computer vision *observes* the table, and a deterministic
rule engine *judges* the result.

Two apps are built on the shared core (Kiroween 2026, Skeleton Crew):

- **Tinkr Quest** (`apps/quest`): a physical puzzle game.
- **Tinkr Inspect** (`apps/inspect`): an assembly and placement verifier.

> Status: early development. See [PROJECT_PLAN.md](PROJECT_PLAN.md).
